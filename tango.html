編輯器使用說明：
• 預填模式：左鍵點格子→黃，右鍵→藍，再次點擊→空
• 約束模式：先選 = 或 X，然後點兩格之間的「縫隙」加上約束（再點同類型可移除）
• 輸入完按「驗證」確認是否唯一解 + 純邏輯可解

遊玩紀錄

自製謎題庫

遊戲規則

  1. 棋盤為 6×6 方格，每格放置 ☀ 黃色（太陽）或 ☾ 藍色（月亮）。
  2. 每一行、每一列必須恰好有 3 黃 3 藍。
  3. 同色最多連續 2 格，不能出現連續 3 個相同顏色。
  4. = 符號連接的兩格必須同色。
  5. X 符號連接的兩格必須異色。
  6. 每個謎題都有唯一解，且可以透過邏輯推理解出（不需要猜）。

操作方式

  • 點一下格子 → 黃色 ☀
  • 再點一下 → 藍色 ☾
  • 再點一下 → 清空
  • UNDO：撤銷上一步
  • RESET：重設所有自填格
  • 顯示答案：直接看到完整答案（紀錄會標記為「已查看解答」）
